# UI-002: Triage nurse avatar in the patient care team

**Status:** Done. Merged into `main`.

## User-visible outcome

In the patient workspace **Oncology Care Team** card, Sarah Jenkins now shows her "SJ" avatar, matching Dr. Aris Thorne's "AT" avatar. It used to be a blank indigo square.

## Change

- `frontend/src/state/workflowState.ts`: Sarah's avatar is one exported constant, `NURSE_AVATAR` (initials SJ on `#0284c7`). Her nurse-task ownership and the care team card both use it, so her avatar is the same everywhere.
- `frontend/src/components/PatientTreatmentHome.tsx`: the care team row renders that avatar as an image with the same size, radius and border as the physician's, and the alt text "Sarah Jenkins, BSN, RN, OCN".

## Verification

- New test in `frontend/tests/access.test.tsx` signs in as the patient and checks that Sarah's avatar image uses `NURSE_AVATAR` and shows "SJ".
- `npm run build` passes; 114 component tests and 14 Playwright tests pass.

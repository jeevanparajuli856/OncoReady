# NAV-001 — Staff navigation clarity

**Status:** Implemented on `feature/NAV-001-staff-navigation`.

## Agreed outcome

- Remove Care Navigator **Appointments**. It currently repeats the Epic integration summary rather than providing an appointment workflow.
- Remove Care Team **Epic context** and **Admin** from the sidebar. The patient case retains its Epic tab, retrieved time, and source-details drawer. Fixed configuration text does not appear as an admin tool.
- When switching between Care Navigator and Care Team, keep a section only if the destination role can open it. Otherwise open **Command Center**. Apply the same rule to a saved session whose section is no longer available.
- Preserve the shared case, patient directory, exceptions, insights, transportation, and clinical workflow behavior.

## Verification

Check both role-switch directions, a shared section, a saved removed route, sidebar contents, and the existing Epic case evidence. Keep the approved visual system unchanged.

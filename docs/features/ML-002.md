# ML-002 — Name the readiness model ReadySignal

**Status:** Implemented on `feature/ML-002-readysignal-name`.

## User-visible outcome

The Insights tab presents OncoReady's readiness model as **ReadySignal**, a named product feature, with no synthetic wording on screen.

## Approved decisions

1. **Chip:** the Insights chip reads **ReadySignal**. Model version labels read **ReadySignal 1.0**, both in the header and in the what-if tag (`Same model · ReadySignal 1.0`). The unavailable state reads "ReadySignal output could not be verified."
2. **Design unchanged:** layout, colors and components are exactly as before. This is a copy-only change.
3. **Data unchanged:** the saved export (`ml-insights.json`), its integrity hash and the internal version `synthetic-logistic-1.0` are unchanged. Only the display string changes.
4. **Stage disclosure:** the human product owner tells the audience at the start that this is a product demo that ships later. The presenter script therefore presents ReadySignal as the working model without a separate on-stage synthetic-data line. It still never claims clinical validation, calibrated risk or patient outcomes.
